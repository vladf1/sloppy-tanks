# Tree surfaces

The six editable tree families and their seeded variations live in `src/game/tree-models.ts`.
Each live tree contains its permanent rooted stump. Destruction hides the upper assembly
and exposes the same stump's growth-ring surface.

`bark-original.png` was generated with the built-in image tool on 2026-09-08.
Prompt: Seamless square game albedo texture of warm neutral brown oak/pine bark,
vertical irregular ridges, narrow cracks, subtle knots and weathered chips. Flat,
uniform diffuse lighting, no cast shadows, trunk silhouette, ground, leaves, moss,
border or text. Moderate contrast; seamless on all edges.

Runtime surfaces are deliberately 256 x 256 for the game's small trees. The original
is preserved here; use `cwebp -resize 256 256 -q 78 bark-original.png -o ../../../public/textures/trees/bark.webp`.
Other source patterns are generated by `node --import tsx scripts/generate-tree-textures.ts`.
