# Tree surfaces

The six editable tree families and their seeded variations live in
`crates/core/src/models/tree_models.rs`.
Each live tree contains its permanent rooted stump. Destruction hides the upper assembly
and exposes the same stump's growth-ring surface.

`bark-original.webp` was generated with the built-in image tool on 2026-09-08.
Prompt: Seamless square game albedo texture of warm neutral brown oak/pine bark,
vertical irregular ridges, narrow cracks, subtle knots and weathered chips. Flat,
uniform diffuse lighting, no cast shadows, trunk silhouette, ground, leaves, moss,
border or text. Moderate contrast; seamless on all edges.

Runtime surfaces are deliberately 256 x 256 for the game's small trees. The original
is preserved here; use `cwebp -resize 256 256 -q 78 bark-original.webp -o ../../../public/textures/trees/bark.webp`.
Other source patterns are generated by `bun scripts/generate-tree-textures.ts`.

`leaf-sprigs.webp` is the lossless source of the broadleaf foliage cards: a 2 × 2 atlas
of lobed oak sprigs (top row) and small ovate birch/aspen sprigs (bottom row), drawn by
`bun scripts/generate-leaf-texture.ts`. Its transparent texels keep a
leaf green so mipmaps do not darken the cut-out edges; `bun run optimize:textures`
writes the 512 px runtime copy with `-exact` to preserve them.

Living trees draw from `public/textures/trees/atlas.webp`, every runtime tree surface
side by side, so a tree or a cell of background trees is one material
(`TREE_ATLAS` in `tree_models.rs`). Rebuild it with
`bun scripts/generate-tree-atlas.ts` after any runtime tree surface changes.
